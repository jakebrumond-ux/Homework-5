Exercise 1

Riemann vs Lebesgue explorer

Riemann cuts the x-axis into n cells and samples f. Lebesgue cuts the y-axis into n levels and adds yk · μ{yk ≤ f < yk+1}. Three Lebesgue-style variants are compared: the lower sum with μ exact from G(t) = μ{f ≥ t}, the layer-cake form, and a counted-preimage version where μ is estimated by binning n samples into levels (no formula for G needed).

∫f ≈ Σk yk·[G(yk) − G(yk+1)] + T·G(T) (layer cake: ∫f = m(b−a) + ∫mT G(t) dt)

Convergence

Absolute error against n on log–log axes (odd n, so jumps fall inside a cell). Dotted lines: 1/n and 1/n². Errors below 10⁻¹⁶ are clamped. The table above reports the observed order between n/10 and n.

Smooth f. Midpoint and trapezoid reach order 2. Lebesgue lower and counted sums have order 1 (a staircase of step Δy). The layer-cake form gains ≈ 1.5 (exact when G is linear, as for |x − ½|).
Jumps. Lebesgue is exact: f is already a simple function. Riemann loses O(1/n) in the jump cell. Unbounded f: all methods are stuck near order ½ (range truncated at T = √n); left and trapezoid fail at x = 0.
Same limit? Yes. Every Riemann-integrable f is Lebesgue-integrable with the same value, and all methods converge to it. The practical difference: Lebesgue needs μ of preimages, cheap when G is analytic, but when estimated from samples (the counted variant) it is Riemann in disguise; compare its error with the midpoint rule.
Where the two theories differ

Pathological functions

Dirichlet

1 on ℚ, 0 on ℝ∖ℚ. Every cell holds both kinds of point: lower Darboux sums are 0, upper sums 1, so not Riemann-integrable. ℚ∩[0,1] is countable, coverable by intervals of length ε/2k: μ = 0, so the Lebesgue integral is 0.

Trap: every double is rational, so naive code returns 1 for both methods. Exact arithmetic or a measure argument is needed.

Thomae

f(p/q) = 1/q, 0 on irrationals. Continuous at every irrational, so Riemann-integrable with integral 0. For Lebesgue, {f ≥ 1/m} is finite, so μ{f ≥ t} = 0 for all t > 0.

Computed live in exact integer arithmetic. Lower sums are 0; the upper Darboux sum Un takes 1/qmin on each cell, qmin being the smallest denominator in it. It decays slowly (roughly n−1/2).

Exercise 2

The standard normal CDF

Φ(x) = ∫−∞x φ(t) dt, φ(t) = e−t²/2/√(2π) = ½[1 + erf(x/√2)]

Six methods: trapezoid and Simpson on ½ + ∫0xφ; composite 5-point Gauss–Legendre; the erf Maclaurin series erf(z) = (2/√π) Σ (−1)k z2k+1/(k!(2k+1)), alternating and so prone to cancellation; the positive-term series Φ = ½ + φ(x)·Σ x2k+1/(2k+1)!!; and the hybrid (that series for |x| < 3, a continued fraction Q(x) = φ(x)/(x + 1/(x + 2/(x + …))) for the tail). Abramowitz–Stegun 26.2.17 (|error| < 7.5·10⁻⁸) is the cheap approximation baseline. Background: Hogg–McKean–Craig §3.4 (normal distribution).

Efficiency for error < 10⁻¹² at x = 1.96: trapezoid ≈ 262,000 exp evaluations (order 2); Simpson ≈ 513 (order 4); Gauss–Legendre 8 nodes; the series 18 terms and one exp. Try the live table: it times every method.
Tails. Computing Φ(−x) as 1 − Φ(x), or as ½ − (a sum), cancels almost all significant digits. Only a direct tail evaluation (continued fraction) keeps full relative accuracy at x = −8 (Φ ≈ 6·10⁻¹⁶). The erf Maclaurin series also degrades for |x| ≳ 4 because its alternating terms grow before they shrink.

Why Φ is not elementary (Liouville)

For rational f and g, ∫ f·eg dx is elementary only if there is a rational R with f = R′ + R·g′. For the Gaussian, f = 1 and g = −x²/2, so we would need

R′(x) − x·R(x) = 1.

If R is a polynomial of degree d, R′ − xR has degree d + 1 ≥ 1 and cannot equal 1. If R has a pole of order k, R′ has order k + 1 there while xR has order k, so the pole cannot cancel. No such R exists: no elementary antiderivative.

That does not make Φ uncomputable. Defining erf(z) = (2/√π)∫0ze−t²dt gives the exact statement Φ(x) = ½[1 + erf(x/√2)], but this only names the integral. Computers still evaluate erf by series, continued fractions, quadrature or tuned rational approximations, which is exactly what the table above compares.
